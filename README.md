## 🏛️ Architecture & Philosophy

* **Static Hosting Separation**: Source repositories, automated scraping pipelines, data processors, and development histories remain in private, dedicated project repositories.
* **Production Distribution**: This repository hosts strictly the production-ready, client-side static builds (`HTML`, `CSS`, `JS`, static assets) organized into clear categorical domains.
* **Zero Overhead**: Direct, dependency-free static delivery powered by GitHub Pages and CDN integrations.
